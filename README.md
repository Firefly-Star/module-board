# module-board

用一张“模块依赖图”维护项目开发进度的小工具（本地 Web，纯静态成品）。

## 概念

- 节点 = 一个模块（python 一个 `.py`；cpp 一个 `.hpp+.cpp`）
- 边 = 依赖（依赖在左，依赖者在右）
- **状态（含自动派生）**：
  - `已实现`（绿）：手动勾选（身体真正写完才勾）
  - `依赖已齐·待实现`（紫，**自动提示**）：冻结=yes 且所有依赖已实现，但尚未手动确认——此时应实现它
  - `已冻结·未实现`（蓝）：冻结=yes，但还有依赖未实现
  - `未冻结·未实现`（琥珀）
- 冻结 = 本体/对外接口锁了不再改；实现 = 依赖链全通 + 本体写完（手动确认）
- 节点可挂“第二轮备注”（第一轮故意放着、之后想改的点）

## 组别

组别由**每张图自己定义**（新建空图无预设）。表单下拉从当前图的 `groups` 读取，可直接输入新组别并自动登记进图的 `groups`（如 cpp / python 随图导出）。

## 折叠语义

- 折叠节点 C = 只断掉指向 C 的边（C 的入边消失），并向下级联
- 只有“断边后失去所有可见连接”的节点才被隐藏；仍被别处引用的节点保持可见
  - 例：c 依赖 a、b；d 依赖 a。折叠 c → a 少一条线但仍可见，b 被隐藏
- 每个节点的折叠状态是**独立的**（c 折叠期间 z/w 本来的折叠状态，展开 c 后依旧保留）

## 文件工作流

- 新建 / 打开 / 保存 / 另存为 / 最近打开（最多 8 条，存于 localStorage）
- 有未保存修改时再新建/打开会弹出：取消 / 另存为… / 保存 / 丢弃修改
- Ctrl+S 保存；关闭页面前有未保存修改会提醒
- 支持 File System Access（保存回同一文件）；不支持的浏览器降级为“导出下载”

## 操作

- 双击背景复位视图；滚轮缩放；拖拽空白平移；Ctrl+S 保存；Ctrl+Z / Ctrl+Shift+Z(或 Ctrl+Y) 撤销/重做（单步）
- **节点可随时拖动**（位置写入节点 `pos` 随图保存）；工具栏「自动布局」一键 dagre 重排后仍可手动微调
- 编辑/连线/折叠**不会自动重排布局**（直观，不跳动）
- 悬停节点看描述/状态（此时露出两端圆点）；点击节点 → 右侧详情
- **连线**：随时可从某节点**右端出口圆点拖到另一节点**（拖线端点会自动吸附到目标入口并高亮）= 后者依赖前者；或详情里增删依赖、点选连线后删除
- **组别**：工具栏「组别」打开组别管理（增删、看数量）；组别随图导出
- **新增节点**：工具栏「新增节点」
- **聚焦**：详情「聚焦依赖子树」= 只看该节点 + 它依赖的整条链
- **下一步实现** = 高亮「依赖已齐·待实现」的节点（依赖实现后你勾选已实现即变绿）

## 使用

```bash
npm install
npm run dev      # 开发
npm run build    # 产出纯静态 dist/
```

## 数据格式

```jsonc
{
  "project": "star-rail-sim-ng",
  "nodes": [
    {
      "id": "python/main",
      "label": "main.py",
      "group": "python",
      "frozen": "yes",            // "no" | "semi" | "yes"
      "implemented": false,
      "desc": "一句话职责",
      "deps": ["python/presenter/team"],   // 依赖的 node id
      "later": ["第一轮之后想改的点"],
      "pos": { "x": 100, "y": 60 }        // 可选：手动布局中心坐标（自动布局忽略）
    }
  ]
}
```
